# Ascensão de Breno: Último Herdeiro

## Sobre o Projeto

Ascensão de Breno: Último Herdeiro é um Action RPG 3D desenvolvido na Unity. O projeto apresenta uma narrativa original, sistemas de progressão, habilidades especiais, exploração de mundo e batalhas contra inimigos poderosos.

A história acompanha Breno, o último herdeiro de uma antiga linhagem, em sua jornada para descobrir a verdade sobre seu passado, despertar poderes ocultos e enfrentar ameaças capazes de mudar o destino do mundo.

# Ascension of Breno: Last Heir

## About the Project

Ascension of Breno: Last Heir is a 3D Action RPG developed with Unity. The project features an original storyline, character progression systems, unique abilities, world exploration, and challenging battles against powerful enemies.

The story follows Breno, the last heir of an ancient bloodline, on his journey to uncover the truth about his past, awaken hidden powers, and face threats capable of changing the fate of the world.

---

## Main Features

- Character progression system
- Skill and attribute development
- Special transformations
- Real-time combat system
- Main and side quests
- 3D world exploration
- Boss battles with unique mechanics
- Inventory system
- Skill tree
- Original storyline
